Cara Aktivasi Database Google Sheets:

  1. Buka Google Cloud Console & aktifkan Google Drive API serta Google Sheets API.
  2. Buat kredensial OAuth 2.0 Client ID (Web Application).
  3. Tambahkan origin URL aplikasi ini ke Authorized JavaScript origins.
  4. Tempel Client ID di bawah lalu klik Otorisasi Google.
